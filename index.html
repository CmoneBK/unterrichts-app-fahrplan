Workshop · Interaktive Web-Apps mit KI

Heute gebaut, morgen im Unterricht

In 12 Schritten von der Idee zur fertigen Lern-App: Die KI bei Fobizz schreibt den Code, CodeSandbox stellt ihn online, und die Klasse öffnet die App über einen Link im Browser, ohne Installation und ohne Anmeldung. Zum Schluss entsteht ein Konzept für weitere Apps.

Code testen und kopieren

    
Die KI antwortet mit einem Code-Block. Mit Vorschau (grau markiert) lässt sich die App schon hier ausprobieren. Änderungswünsche gleich im Chat nennen, z. B. „Mach die Schrift größer“. Passt alles, den Code mit 1 Kopieren in die Zwischenablage holen.

    
    
Code bricht ab? Der Code muss mit </html> enden. Fehlt das Ende, in den Chat schreiben: „Gib den vollständigen Code noch einmal in einem Block aus.“

Abschnitt D · Alternative zu B und C
Die App über Taskcards bereitstellen

  
Statt CodeSandbox lässt sich die App auch als Datei auf eine Taskcards-Pinnwand legen. Dafür wird der Code nicht kopiert, sondern als HTML-Datei heruntergeladen.


  

    
D1

    
HTML-Datei bei Fobizz herunterladen

    
Im Code-Block der KI-Antwort auf 1 den Download-Pfeil links neben Code klicken („Als HTML-Datei herunterladen“). Die Datei landet im Download-Ordner.

    
  


  

    
D2

    
Neue Pinnwand anlegen

    
In Taskcards unter Pinnwände unten rechts auf das 1 + klicken (erstes Bild).
Im Fenster „Pinnwand erstellen“ (zweites Bild) 1 einen Namen eintragen und oben rechts mit 2 dem Speichern-Symbol bestätigen. Die übrigen Einstellungen können so bleiben.

    
    
  


  

    
D3

    
Keine Vorlage verwenden

    
Bei der Frage „Möchten Sie eine Vorlage verwenden?“ auf 1 Nein, danke! klicken.

    
  


  

    
D4

    
Karte anlegen und Datei importieren

    
Auf der leeren Pinnwand mit dem 1 + eine neue Karte erstellen (linkes Bild). In der neuen Karte auf die 1 Wolke mit Pfeil (Datei importieren) klicken (rechtes Bild) und die heruntergeladene HTML-Datei aus dem Download-Ordner auswählen.

    

  


  

    
D5

    
App öffnen

    
Die Karte zeigt jetzt die Datei mit dem Button 1 Besuchen. Ein Klick darauf öffnet die App. Vorher erscheint die Warnung „Potentiell unsicherer Inhalt“, weil Taskcards hochgeladene Dateien nicht prüfen kann. Mit 2 Ja bestätigen.

    

      
      
    

    
Danach die Pinnwand wie gewohnt über Taskcards mit der Klasse teilen. Die Schüler sehen dieselbe Warnung. Am besten vorher ansagen, dass sie hier mit „Ja“ bestätigen dürfen.

  







  
Abschnitt E · Zum Weiterarbeiten
Ein Konzept für weitere Apps

  
Die erste App läuft. Jetzt lässt man sich von der KI einen Vorrat an weiteren App-Ideen für das eigene Fach erstellen, jeweils mit fertigem Prompt. Damit lassen sich später weitere Apps ohne Workshop bauen.


  

    
E1

    
Konzept anfordern

    
Im Fobizz KI Chat oben links auf Chat starten klicken (neuer Chat), die Felder ausfüllen, den Prompt kopieren und abschicken.

    

      

        
        
        
        
      

      

    

  


  

    
E2

    
Lesen, auswählen und anpassen

    
Die KI liefert eine Übersicht mit Titel, Lernziel, Funktionen und Einsatz im Unterricht, dazu zu jeder App einen Kurzprompt. In Ruhe lesen und nachsteuern, z. B.:

    
    
      
  • „Ersetze Idee 3 durch etwas Praktischeres.“
    • 
      
  • „Mehr Ideen für Lernfeld 6.“
    • 
      
  • „Sortiere nach Aufwand für mich als Lehrkraft.“
    • 
      
  • „Welche Idee eignet sich für Vertretungsstunden?“
    • 
    

  


  

    
E3

    
Konzept sichern

    
Oben rechts im Fobizz-Chat auf PDF speichern klicken. Das Konzept liegt dann als PDF im Download-Ordner, z. B. zum Ablegen im Fachordner oder auf einer Taskcards-Pinnwand für die Fachkollegen.

  


  

    
E4

    
Später: die nächste App bauen

    
Einen Kurzprompt aus dem Konzept kopieren, in einem neuen Fobizz-Chat abschicken und ab Schritt 4 weitermachen: lesen, anpassen, „Erstelle die App“, dann wie gewohnt über CodeSandbox oder Taskcards bereitstellen.

  







  
Abschnitt F · Optionaler Ausblick
Der Profi-Weg: Claude und GitHub

  
Fobizz und CodeSandbox reichen für die meisten Unterrichts-Apps. Wer größere Projekte baut, Apps über Jahre pflegt oder mit Kollegen gemeinsam daran arbeitet, kommt mit diesen beiden Werkzeugen weiter.


  

    

      
Einstieg (dieser Workshop)Profi-Weg

      
        
App schreibenFobizz KI ChatClaude: zeigt die App direkt neben dem Chat und ändert sie gezielt Stück für Stück

        
Code ablegenCodeSandboxGitHub-Repository: jede Änderung wird als Version gespeichert

        
Veröffentlichencsb.app-Link oder TaskcardsGitHub Pages: kostenlose Webadresse wie name.github.io/app

        
ÄndernCode komplett ersetzennur die geänderten Stellen, alte Versionen bleiben abrufbar

        
ZusammenarbeitFork einer Sandboxmehrere Personen an einem Projekt, Änderungen nachvollziehbar

      
    

  


  

    
F1

    
Mit Claude entwickeln

    
In Claude die App beschreiben wie in Schritt 4. Claude baut sie und zeigt sie sofort als lauffähige Vorschau neben dem Chat. Änderungswünsche („Der Button soll größer“, „Füge Level 2 hinzu“) setzt Claude direkt in der bestehenden App um, statt alles neu zu schreiben. Für größere Projekte arbeitet Claude Code direkt in den Projektdateien und kann Änderungen selbst nach GitHub übertragen.

  


  

    
F2

    
Mit GitHub verwalten

    
Auf github.com ein kostenloses Konto anlegen und pro App ein Repository (Projektordner) erstellen. Die index.html hochladen. Jede spätere Änderung wird als eigene Version gespeichert und lässt sich jederzeit zurückholen. Auch CodeSandbox kann über das GitHub-Symbol links im Editor mit einem Repository verbunden werden.

  


  

    
F3

    
Mit GitHub Pages veröffentlichen

    
Im Repository unter Settings → Pages die Veröffentlichung einschalten. Nach kurzer Zeit ist die App unter einer festen Adresse wie name.github.io/app erreichbar, ohne den „Open Sandbox“-Button von CodeSandbox. Im kostenlosen Konto funktioniert das für öffentliche Repositorys.

  


  
Vor dem Einsatz klären: Claude und GitHub sind keine von der Schule bereitgestellten Dienste. Die Schüler kommen damit nicht in Berührung, sie öffnen nur den Link. Trotzdem gilt wie immer: keine Schülerdaten in die KI und keine personenbezogenen Daten in die App.






  
Hilfe bei Problemen

  
Die Vorschau bleibt weiß oder zeigt nur Text
Meist ist der Code unvollständig (endet nicht mit </html>) oder wurde nur teilweise markiert. Bei Fobizz den vollständigen Code anfordern, in index.html noch einmal alles löschen und neu einfügen.

  
Schüler sehen eine Anmeldeseite
Die Sandbox steht auf Private. Im Share-Dialog auf Public oder Unlisted umstellen.

  
Meine Änderungen kommen nicht an
CodeSandbox speichert automatisch. In der Vorschau auf den runden Pfeil klicken bzw. die App-Seite im Browser neu laden (F5).

  
Speichert die App Daten von Schülern?
Nicht, solange der Prompt „keine Datenspeicherung“ vorgibt. Die App läuft dann nur im Browser des jeweiligen Geräts. Trotzdem vor dem Einsatz kurz prüfen, ob die App nach Namen oder anderen persönlichen Angaben fragt.
