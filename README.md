# Unterrichts-App-Fahrplan

Bebilderte Schritt-für-Schritt-Anleitung aus dem Workshop „Heute gebaut, morgen im Unterricht: Interaktive Web-Apps mit KI erstellen“.

Die Anleitung zeigt, wie Lehrkräfte mit dem Fobizz KI Chat eine interaktive Lern-App erstellen und sie über CodeSandbox, Taskcards oder GitHub Pages für ihre Klasse bereitstellen.

**Online ansehen:** https://cmonebk.github.io/unterrichts-app-fahrplan/

Die gesamte Anleitung steckt in einer einzigen Datei (`index.html`), die Screenshots sind eingebettet.
